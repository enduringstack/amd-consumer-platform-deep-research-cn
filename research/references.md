# 引用与复核指南

## 引用格式

正文使用 `[A001]` 至 `[A080]` 的稳定标识，完整条目位于 `sources-amd.md`。标识表达“该来源能支持紧邻事实”，不表达对整段所有推论的背书。一个段落若混合规格、市场数据和推断，应分别在相应句子后引用。

## 来源优先级

优先顺序为：AMD/SEC 原始申报；AMD 产品规格与架构文档；AMD 官方软件文档和源码仓库；平台拥有者的终端规格；公开标准组织；最后才是完整披露测试方法的第三方测量。本报告没有把搜索摘要、聚合参数站、泄露或论坛消息列为路线图证据。[A078][A080]

## 时间与版本

网页会原地更新，因此引用条目记录访问日 2026-08-04。软件支持结论必须同时给出文档版本或“latest 页面在快照日的状态”。若读者在以后看到不同矩阵，应以当时版本归档重现本报告，而不是假定现在页面仍代表当时。

## 厂商测试

AMD 新闻稿和产品页中的相对性能属于厂商实验。只有当比较系统、内存、驱动、应用、分辨率、功耗模式、样本与统计方法足够清楚时，才能复述具体比例；否则只用来确认产品定位。理论 TOPS/TFLOPS 还必须标注精度、稀疏、矩阵/向量和 boost 条件。

## 争议处理

当产品页、规格数据库和开发文档不一致时，先判断它们是否描述不同 SKU、封装或软件版本。仍冲突时，在正文并列陈述并标注日期，不自行“平均”。路线图和上市状态分为已宣布、已送样、合作伙伴系统已宣布、一般可用四级，不能互换。

## 复核入口

读者可运行：

```bash
bash scripts/assemble_report.sh
bash scripts/check_report.sh
bash scripts/audit_citations.sh
perl scripts/check_duplicates.pl
bash scripts/check_links.sh
```

合并版由源章节生成；任何直接编辑都会在下次装配时被覆盖。
